# 灵脉重启 · 第一、二集制作包

剧本与分镜脚本分别存放，两集各有独立文件。第一集102.100秒，第二集59.233333秒，均为30fps横屏。分镜共计81镜。

固定资产共14张PNG：5张人物、3张生物、2张道具板、4张场景。P03锁链与P02武器共板，不重复生成。人物统一一张横屏16:9，左上半身特写、右正面／侧面／背面全身。

## 复用与状态

- 秦澈两集共用C01，血迹、伤痕、金瞳、额间印记和金光通过状态变化实现。衣袖破损保留，伤口恢复不等于衣服恢复。
- 传承玉佩两集共用P01，常态青绿、激活金光，吸纳与储能通过纹路亮度和光流表现。
- 第一集凶兽、第二集狼兽、怨灵为不同造型。守卫和族人各用一份基础资产，通过实例形成群体。
- 星海中的巨型虚影使用秦澈的放大透明形态，不增设神灵人物。父亲、母亲仅在对白中提及，不生成其资产。
- 金环、青焰、黑气、骨骼光路、自愈和剑气以分镜内效果实现，不增加重复静态图。

## 使用

制作包预览.html可直接浏览两集剧本、分镜和资产。分镜CSV为UTF-8 BOM，可导入Excel。PNG是视觉制作参考；人物未在视频中完整展示的背面及鞋靴细节按同一造型补绘。生成图用于固定外观，画面依据用于核对已出现的部位。

中文台词按画面字幕与音轨交叉整理；“归虚”保留视频写法。画外音“混沌灵脉”不赋予额外人物身份。未增加第二集蒙面人与秦澈交战、夺取灵脉或胜负结果。

声音栏标为制作建议，涵盖环境声、动作声、灵力效果和音乐方向，未提供独立音效或音乐文件。镜段时间已按30fps对齐，实际重剪可按表中帧号微调。
